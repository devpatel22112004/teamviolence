## 🔄 How to Update Data

### Update Team Members
```bash
# Connect to MongoDB
mongosh "your_connection_string"
use teamviolence

# Add new team member
db.teammembers.insertOne({
  name: "New Player Name",
  role: "Role Title",
  kills: 5000,
  winRate: 75,
  description: "Player description",
  ingameName: "VioLencE TAG",
  since: 2024,
  category: "Organizer",
  image: "/Line_up/player.jpg",
  socials: {
    discord: "https://discord.gg/AmezSUbP",
    instagram: "https://www.instagram.com/teamviolenceesports",
    whatsapp: "https://chat.whatsapp.com/BRydZHpa1ARDNp2DTdBrlu"
  }
})

# Update existing member
db.teammembers.updateOne(
  { name: "Dev Patel" },
  { $set: { kills: 5500, winRate: 80 } }
)
```

### Update Tournament
```bash
# Update tournament slots or registrations
db.tournaments.updateOne(
  { title: "Team VioLencE Pro Championship" },
  { $set: { registeredTeams: 15 } }
)

# Update prize pool
db.tournaments.updateOne(
  { title: "Team VioLencE Pro Championship" },
  { $set: { 
    prizePool: 5000,
    "prizeBreakdown.first": 2500
  }}
)
```
